# Strategic Survival Engine

Кросс-языковая интегрированная экосистема сборки для симуляции выживания.

## Политика языков (Language Policy)

| Язык   | Зона ответственности          | Инструмент сборки |
|--------|-------------------------------|-------------------|
| C++    | Ядро симуляции, физика        | CMake + GCC/Clang |
| Rust   | Био-матрицы, безопасность     | Cargo             |
| C#     | Логика игрока, интерфейс     | dotnet SDK        |
| Python | AI-расчёты, скрипты          | venv + pip        |

## Быстрый старт

1. Установите инструменты: `rustup`, `cmake`, `.NET SDK`, компилятор C++.
2. Клонируйте репозиторий.
3. Откройте в VS Code — расширения установятся автоматически.
4. Нажмите `Ctrl+Shift+B` для полной сборки.
