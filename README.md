## 1. Философия

Это не «игра» в привычном смысле. Это **мир**, который описывается
и проявляется тогда, когда есть наблюдатель.

**Три принципа:**

1. **Мир существует как 0 и 1.** Не как картинка. Как данные.
2. **Картинка рождается в момент восприятия.**
   Ушёл наблюдатель — картинка исчезла, данные остались.
3. **Наблюдатель ≠ игрок.** Наблюдатель — точка зрения.
   Игрок — тело в мире.

**Следствия:**

- Мир может быть огромным без нагрузки на память.
- **Детерминизм:** один seed = один мир всегда.
- Расширяемость: новый объект = новый файл данных, а не правка движка.
- Всё, что **видно** — вычисляется каждый кадр.
- Всё, что **не видно** — существует как данные и не рисуется.

## 2. Игра

**Жанр:** симуляция выживания в пост-апокалипсисе.
**Вид:** вид сверху, без 3D. Стилизация под классические top-down RPG.
**Фокус:** тактика, ориентация, выживание, слух и зрение.

**Сюжет:**

Катастрофа уничтожила 95% человечества. Остались только иммунные — и они
тоже гибнут от зомби. Рождаются новые герои, появляются в одном из
**6 городов** и начинают своё путешествие.

**Игровые принципы:**

- **Мир — шар.** Уйдя за правый край — появляешься слева.
- **Нет карты.** Есть маршруты и память. Ориентация — навык.
- **Смерть — не конец.** Возрождение в точке привязки без лута.
- **Города** — основные и второстепенные, защищены стенами.
- **Границы мира — естественные опасности:** жара, холод, вода.
- **Шум** — главная механика. Физика звука: дБ, затухание.
- **Зрение** — три зоны: фокус, периферия, слепая зона.
- **Мир живёт сам.** Зомби охотятся, ходят, ищут добычу
  независимо от игрока.

## 3. Технологический стек

| Язык     | Что делает                                    | Инструмент   |
|----------|-----------------------------------------------|--------------|
| **C++**  | Окно, мир, ячейки, стриминг, UI-layout, шум   | CMake + MSVC |
| **Rust** | Герой, зомби, срезы тела, шум шага, анимация  | Cargo        |
| **C#**   | Скрипты логики (PlayerController, AI)         | dotnet SDK   |
| **Python** | Прототипы (не участвуют в сборке)          | venv         |

**Единая цепочка сборки:** Cargo → CMake → dotnet.

**Принцип разделения:**

- **Rust** — горячий цикл (рендер, расчёты, физика шума).
- **C++** — среда (окно, мир, ячейки, UI).
- **C#** — логика игрока, AI-состояния.

## 6. Установка и сборка

### Клонирование

```powershell
git clone https://github.com/Reppatola/strategic-survival-engine.git
cd strategic-survival-engine
```

### Сборка Rust (первый раз обязательно вручную)

```powershell
cargo build --release
```

**Ожидаемый вывод:**
```
Compiling rust-hero v0.1.0
Finished `release` profile [optimized] target(s) in XXs
```

Файл `target/release/rust_hero.lib` создан.

### Сборка C++ через VS Code

1. Открыть папку в VS Code.
2. `Ctrl+Shift+P` → **`CMake: Delete Cache and Reconfigure`**
3. `Ctrl+Shift+P` → **`CMake: build`**

**Ожидаемый вывод:**
```
sse_prototype.vcxproj -> ...\build\Release\sse_prototype.exe
Build finished with exit code 0
```

### Если ошибки линковки

**`LNK2001 unresolved external __imp_NtWriteFile`** — добавь в `CMakeLists.txt`:

```cmake
target_link_libraries(sse_prototype PRIVATE
    user32 gdi32 ntdll ws2_32 advapi32
    ${RUST_HERO_LIB}
)
```

**Русский язык в консоли «кракозябры»** — в `CMakeLists.txt`:

```cmake
add_compile_options($<$<CXX_COMPILER_ID:MSVC>:/utf-8>)
```

Затем обязательно **`Delete Cache and Reconfigure`** + **`CMake: build`**.

## 8. Что уже работает

### Мир

- Шар 6144 × 6144 px.
- Стриминг ячеек (загрузка вокруг игрока).
- Кэш ячеек — список активных пикселей.
- Трава — 2–3 px, густая, мозаика оттенков.
- Fade-зона с плавным исчезновением к краю.

### Герой

- Тело из **срезов** (не спрайт).
- 9 частей + лицо + уши + нос.
- **Поворот** при движении.
- **Анимация** рук и ног через синус фазы.
- Таблица анимации: 2.0 шага/с при ходьбе, 3.3 при беге.
- Проекция строго сверху.

### Зрение героя

- **Фокус ±30°** — ярко.
- **Периферия ±100°** — приглушённо.
- **Слепая зона сзади** — невидимо.
- Поворот героя → поворот сектора зрения.

### Зомби

- Тело из срезов (бледные цвета, тонкое).
- **Спрайт-кэш:** 48 предвычисленных спрайтов.
- AI с тремя состояниями: IDLE / ALERT / CHASE.
- **Зрение зомби:** периферия → ALERT (поворот), фокус → CHASE (движение).
- Движение всегда — только визуализация может быть скрыта.

### Физика шума

- **Таблица источников** (0–160 дБ).
- **Формула шага:** `L = 10·log10(η·E / P0·Δt)`.
- **Затухание:** `L2 = L1 − 20·log10(R)`.
- **Радиус слышимости:** `R = 10^((L1−threshold)/20)`.
- Связь с анимацией (шаги/с = freq/π).

### Кросс-языковая сборка

- Cargo → CMake → dotnet.
- Rust staticlib линкуется в C++.
- FFI: 6+ функций.

## 9. Ключевые подсистемы

### Срезы (HSlice)

Форма тела описывается **горизонтальными срезами**. Каждый срез —
эллипс на определённой высоте Z.

```rust
pub struct HSlice {
    pub z: f32,        // высота
    pub width: f32,    // ширина
    pub depth: f32,    // глубина
    pub off_x: f32,    // смещение центра по X
    pub off_y: f32,    // смещение центра по Y
}
```

Тело — **не массив пикселей**, а **набор срезов**. Из срезов
вычисляется, где поверхность — `highest_z_local`.

### Спрайт-кэш зомби

48 спрайтов (4 позы × 12 фаз) строятся **один раз** при старте.
При рендере — просто копируем пиксели. В 10 раз быстрее ray marching.

### Фаза анимации

Один цикл = 2 шага = 2π. Скорость роста:
- Красться: `π` рад/с — 1.0 шага/с.
- Ходьба:   `2π` рад/с — 2.0 шага/с.
- Бег:      `~10.4` рад/с — 3.3 шага/с.

### Зрение героя

```cpp
dot = (dx·sin_f + dy·cos_f) / d
dot >  0.866  →  фокус      (255)
dot > -0.174  →  периферия  (140)
иначе          →  слепая    (0)
```

### Зрение зомби

Та же формула, но **без визуальной отрисовки** —
используется для AI-состояний.

## 10. Производительность

### Текущие показатели

| Метрика              | Значение      |
|----------------------|---------------|
| Размер Release exe   | ~40 KB        |
| RAM (прототип)       | ~15 MB        |
| FPS без зомби        | 64            |
| FPS с одним зомби    | 60+           |
| Размер Rust staticlib | 3.7 MB       |
| Спрайт-кэш           | 48 × 32 KB    |

### Сравнение с классическим 3D

| Метрика | 3D-движок   | Наш подход      | Отношение      |
|---------|-------------|-----------------|----------------|
| Диск    | 5–50 GB     | < 1 MB          | 5000× меньше   |
| RAM     | 1–8 GB      | ~15 MB          | 500× меньше    |
| Код     | 100 000+    | ~5 000 строк    | 20× меньше     |

### Оптимизации

- **Кэш ячеек** — активные пиксели, не буфер.
- **Спрайт-кэш зомби** — 48 предвычисленных спрайтов.
- **Fade-таблица** — предвычисленная маска зрения.
- **Ray marching** только внутри спрайта.
- **LTO + codegen-units=1** для Rust.
- **/O2 /Oi /Ot /GL** для C++.

### Принцип оптимизации

> **Не рисуем то, что не видно.**
> **Не считаем то, что не меняется.**
> **Не храним то, что можно вычислить.**
