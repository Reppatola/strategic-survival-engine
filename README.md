## 1. Философия

Это не «игра». Это **мир**, который описывается и проявляется тогда, когда есть наблюдатель.

**Три принципа:**

1. Мир существует как 0 и 1 — не как картинка, а как данные.
2. Картинка рождается в момент восприятия. Ушёл наблюдатель — картинка исчезла, данные остались.
3. Наблюдатель ≠ игрок. Наблюдатель — точка зрения. Игрок — тело в мире.

**Что это даёт:**

- Мир может быть огромным без нагрузки на память.
- Детерминизм: один seed = один мир всегда.
- Расширяемость: новый объект = новый файл данных, а не правка движка.

## 2. Игра

**Жанр:** симуляция выживания в пост-апокалипсисе.
**Вид:** сверху (top-down), без 3D. Стилизация под классические top-down RPG.
**Фокус:** тактика, ориентация, выживание. Не графика.

**Сюжет:**

Катастрофа уничтожила 95% человечества. Остались только иммунные — и они тоже гибнут от зомби. Рождаются новые герои, появляются в одном из **6 городов** и начинают своё путешествие.

**Игровые принципы:**

- Мир — шар. Уйдя за правый край — появляешься слева.
- Нет карты. Есть маршруты и память. Ориентация — навык.
- Смерть — не конец. Возрождение в точке привязки без лута.
- Города и важные точки прописаны в данных. Всё вокруг — живой организм.
- Границы мира — естественные опасности (жара, холод), а не стены.

## 6. Установка и сборка

### Клонирование

```powershell
git clone https://github.com/Reppatola/strategic-survival-engine.git
cd strategic-survival-engine
```

### Сборка через VS Code

1. Открыть папку проекта в VS Code.
2. `Ctrl+Shift+P` → **`CMake: Delete Cache and Reconfigure`**
3. `Ctrl+Shift+P` → **`CMake: build`**

### Сборка через терминал

```powershell
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

### Проверка

```powershell
Get-ChildItem -Recurse -Filter sse_prototype.exe
```

Должен найтись в `build\Release\sse_prototype.exe`.

## 10. Ключевые технические решения

### Шар как замкнутый мир

Мир — сфера. Уйдя за правый край — появляешься слева.

```
WORLD_SIZE = 3072 px
Обзор = 760 px
Отношение = 4.04× (шар в 4 раза больше обзора)
```

Математика: `wrapDelta(d)` возвращает кратчайший путь на шаре.

### Стриминг ячеек

Мир не хранится целиком. Только то, что близко к наблюдателю.

```
R_LOAD = 800 px — граница загрузки
R_FADE = 420 px — граница затухания
R_CORE = 40 px  — зона полной чёткости
```

Ячейки ближе `R_LOAD` — загружены. Дальше `R_LOAD × 1.4` — освобождаются.

### Кэш ячеек

Каждая ячейка генерируется один раз, рисуется один раз в свой буфер. При повторном попадании — берётся из кэша.

Хранится не буфер 64×64 (4096 пикселей), а список активных пикселей (~500). Ускорение 5–10×.

### Размытие зрения

Размытие — свойство наблюдателя, а не мира. Построено в экранных координатах, привязано к центру экрана.

```
a = exp(-(d - R_CORE)² / 2σ²)
σ = (R_FADE - R_CORE) / 2.5
```

### Прямая растеризация

Никаких `std::vector<Pixel>` в hot loop. Всё рисуется прямо в буфер:

- Брезенхэм для линий
- `std::fill` для фона
- Блит ячейки — копия списка активных пикселей

### Почему C++, а не C#

Ядро должно работать без GC-пауз. C# — для высокоуровневой логики.

### Почему Win32, а не SDL/OpenGL

- Минимум зависимостей — ноль сторонних библиотек.
- Работает везде, где Windows.
- Позже можно добавить SDL как альтернативную платформу — не переписывая мир.

### Почему программный рендер, а не шейдеры

- Детерминизм — одинаковый результат на всех машинах.
- Работает без GPU — на слабом железе.
- Меньше кода — 100 строк вместо 5000 строк шейдеров.

### Почему данные отдельно от кода

Изменение травы не должно требовать пересборки движка. Один JSON — и другой биом.

## 12. Настройка

Все параметры — в `src/app/Config.h`.

### Размеры области обзора

```cpp
constexpr float R_CORE = 40.0f;    // зона чёткости (px)
constexpr float R_FADE = 420.0f;   // граница размытия (px)
constexpr float R_LOAD = 800.0f;   // буфер загрузки (px)
```

### Мир

```cpp
constexpr int CELL_SIZE   = 64;    // размер ячейки (px)
constexpr int WORLD_CELLS = 48;    // 48 × 48 ячеек
constexpr int WORLD_SIZE  = 3072;  // размер шара (px)
```

### Плотность травы

```cpp
constexpr float CELL_DENSITY = 0.06f;  // травинок на пиксель ячейки
```

### Стриминг

```cpp
constexpr int LOAD_PER_FRAME_BASE = 12;    // ячеек за кадр
constexpr int LOAD_QUEUE_FAST_THRESHOLD = 100;  // порог адаптивности
```

**Как менять:** правишь значение → `CMake: build` → запуск.
